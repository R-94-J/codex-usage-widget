# Codex 贴边用量条设计

日期：2026-10-23。用户已同意使用跟随 Codex 的贴边状态条。

## 交付与边界
- 独立 Windows 工具，附着于 Codex / ChatGPT 桌面主窗口，不修改或注入宿主程序。
- 常驻小条默认位于窗口右上方内容边缘，避开系统窗口按钮；可拖动调整相对位置，设置保存到本机。
- 自动跟随移动与尺寸变化；宿主最小化或不在前台时隐藏，回到宿主时恢复；不抢焦点。
- 无宿主时后台等待，保留托盘/启动入口；不添加开机启动、不改变系统安全设置。
- 一键启动，单实例；最终提供不依赖用户自行安装 Python 的 Windows 可执行程序和源代码。

## 数据与隐私
- 只读 CODEX_HOME（默认用户目录 .codex）下 sessions 和 archived_sessions 的 JSONL。
- 仅提取 session_meta、turn_context、event_msg/token_count；不持久化或上传提示词、回复、API 密钥。
- 启动扫描历史，之后按文件游标增量读取，每 2 秒刷新；窗口跟随每 250ms 刷新。
- 展示最近活跃主会话（不是承诺识别当前选中的 UI 聊天）与今日全部本机已记录会话的合计。
- 可手动锁定会话；后台子代理不抢占自动选择；今天按 Asia/Shanghai UTC+8。
- 输入已包含缓存；输出已包含推理。总 token = 输入 + 输出，不重复加缓存或推理。
- 累计计数去重，跨目录复制和归档不重复；处理半行、坏行、文件截断/替换、计数重置。
- 缺失历史的初始累计不冒充今日用量；分叉复制历史不重复收费。

## 费用
- 显示“API参考估算”，绝不称为实际账单、余额或订阅扣费。
- 默认已核验模型使用 2026-10-23 官方 API 参考价（USD），未知模型显示未定价。
- 支持用户按模型配置非缓存输入、缓存读取、缓存写入和输出每百万 token 单价，人民币或美元，渠道倍率。
- 按单次请求处理服务档位与长上下文阶梯；无法确认的请求标记未定价/部分估算，不以累计上下文误用阶梯。
- GPT-6 Astra 参考价 USD/1M: input 10, cached 1, write 12.5, output 50；超过 272000 输入时输入/缓存 2x、输出 1.5x；Fast 2x、Flex/Batch 0.5x。
- 价格仅快照，不在后台自动联网，不推定第三方实际费率。设置可覆盖。

## 界面
深色紧凑条：状态点、最近活跃会话 token、API参考估算金额、今日 token/金额、展开、设置、关闭。
展开显示输入/缓存读写/输出、模型、会话标识和数据覆盖说明。右键菜单提供锁定、详情、设置、退出。双击启动恢复隐藏实例。
设置窗口由用户点击才激活；可编辑价格、币种、渠道倍率与相对位置。缩小条不隐藏估算标签。

## 验收
1. 合成日志单测证明计数去重、跨日、缓存计算、未知价格、增量与异常安全。
2. Windows 自建测试宿主验证跟随位置、最小化隐藏、恢复显示、无焦点抢占与单实例。
3. 对照真实日志的独立求和验证统计，并保存只含计数的证据。
4. 打包后运行 smoke test，截取仅工具窗口验证排版；最后启动交付程序附着到实际宿主。
